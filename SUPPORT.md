# Support policy

Finish Forge Studio is maintained on a voluntary, best-effort basis. There is
no guaranteed response time, service level, uptime, compatibility period,
feature roadmap, data-recovery service, manufacturing consultation, or private
support entitlement.

Use GitHub issues for reproducible software defects and feature proposals. Use
discussions, if enabled, for general questions. Before posting:

- remove confidential or proprietary files and personal data;
- reproduce with the demo part or a redistributable minimal model;
- include app version, browser, operating system, relevant settings, and the
  exact error message;
- state whether the failure occurs before or after import, texturing, or export.

Security concerns belong in the private channel described in `SECURITY.md`.
Requests for production texture certification, legal interpretation, printer
safety approval, mold design, tolerance sign-off, or regulated-use validation
are outside community support scope and require qualified professionals.

Donations, if enabled, do not create support priority or an obligation to
implement a request.
