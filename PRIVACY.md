# Privacy statement

## Supplied local application

Finish Forge Studio 0.3.0 processes imported STEP files and custom height maps
in the user's browser. The supplied build has no application analytics,
advertising, account system, cloud storage, or intentional file-upload feature.
The Windows launcher serves static files on the loopback interface
`127.0.0.1`.

Browser memory may contain imported geometry and generated meshes until the tab
is closed or reloaded. Exported files are written through the browser's normal
download mechanism. The project does not promise secure erasure.

## Limits

The browser, operating system, endpoint security tools, extensions, GitHub,
hosting provider, network environment, or modified forks may collect or expose
information independently. Review those policies and the actual deployed source
before using confidential CAD. Do not use a public host for sensitive files
without a separate security and privacy assessment.

## GitHub participation

Issues, pull requests, discussions, commits, and profile information submitted
to a public repository are public and retained under GitHub's terms. Do not post
personal, confidential, export-controlled, customer-controlled, or proprietary
information.

## Future donations

If donations are enabled, the selected payment platform will process payment
and identity data under its own terms and privacy policy. Maintainers should not
request card or bank details through repository issues or email and should
publish any material change to this statement before enabling a new integration.
