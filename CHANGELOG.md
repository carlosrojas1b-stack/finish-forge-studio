# Changelog

This project follows a simple chronological changelog. Until a stable 1.0
release, interfaces, presets, generated geometry, and project files may change.

## 0.3.0 — 2026-08-04

- Renamed the application to Finish Forge Studio.
- Added tabbed MT, SPI/SPE, VDI 3400, organic, and miscellaneous finish libraries.
- Added universal depth, spacing, and rotation controls with dimensional warnings.
- Added 25 µm and 50 µm resin profiles.
- Added physical pattern scaling, light-grey visualization background, and
  expanded texture presets.
- Improved STEP import robustness and face selection workflow.
- Added GitHub community, legal, safety, privacy, and maintainer documentation.
